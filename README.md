# blogs.ewanjohndennis

> *"Verba Volant, Scripta Manent"*
> Spoken words fly away, written words remain.

Personal blog. Writing about what I build, what I learn, and what I think about.

**Live:** [blogs-ewanjohndennis.vercel.app](https://blogs-ewanjohndennis.vercel.app/)

---

## What this is

Every post is a `.md` file, version-controlled with Git, rendered via Vercel. No CMS,
no dashboard — just write, commit, push.

Content falls into a few loose categories:

- **Internship logs** — what actually happened, not the polished version
- **Project writeups** — architecture decisions, what broke, what I'd do differently
- **Case studies** — debugging stories and engineering trade-offs worth documenting
- **Essays** — opinions on tech, open source, and the craft of building software

---

## Possible Shift in Architecture (Not Decided Yet, In Plans)

I've been thinking about migrating this to [Obsidian](https://obsidian.md/) +
[Quartz](https://quartz.jzhao.xyz/). Honestly, the end result is nearly identical —
markdown files, Git, static site. The difference is more about workflow than output.

Obsidian gives me a better local writing environment: graph view, backlinks, and the
ability to connect ideas across notes before they become posts. Quartz handles the
static site generation side and has slightly more flexibility in theming.

Whether the friction of migrating is worth that workflow improvement is still an open
question. If you've made the switch, I'd like to hear how it went.
